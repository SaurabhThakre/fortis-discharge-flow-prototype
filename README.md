# Fortis Discharge Flow Prototype

An interactive prototype from Group 7’s Business Process Improvement project at IIM Bangalore. The demo follows fictional inpatient cases from the doctor’s discharge decision through summary approval, insurance checks, billing, patient handover, and bed readiness.

## Run the demo

[Open the live prototype on GitHub Pages](https://saurabhthakre.github.io/fortis-discharge-flow-prototype/)

Open `index.html` in a modern browser. The prototype runs as a single HTML file with no build step. Changes stay in the current browser. Use **Reset demo** to restore the sample cases.

## Try the patient’s live bill

1. Open **WhatsApp updates** and select a sample patient.
2. In the patient’s chat, tap **View live bill**. The chat shows the latest total, bill status, and retrieval time, followed by each charge’s name, quantity, unit price, and line total. Charges are grouped into room and nursing, supplies and equipment, investigations, and pharmacy. Patients can repeat the request whenever they want to see the latest figures.
3. To see the total change, choose **Rohan Mehta** and fetch the bill before recording the pharmacy receipt. Open his case from the **Discharge dashboard**, choose **Confirm receipt & bill update**, then return to **WhatsApp updates** and fetch again. The new bill lists each returned medicine and its credit. The total drops from ₹26,200 to ₹25,000. Earlier replies retain their original amounts.

The hospital’s sample message menu covers discharge status and coordinator contact. Billing lookups are initiated by the patient. The demo uses fictional data and simulates WhatsApp and hospital billing in the browser.
